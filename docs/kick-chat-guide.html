KICK CHAT / CENTRIFUGO / DEVELOPER GUIDE

روش جدید دریافت چت Kick

راهنمای پیاده‌سازی برای برنامه‌نویس، همراه با Worker مستقل و کلاینت کامل مرورگر؛ همان ساختار اتصال استفاده‌شده در ChatBattle و instaQ.

به‌روزرسانی: ۱۳ اکتبر ۲۰۲۶. فایل مستقل و آفلاین است؛ نمونه‌کدها با بازشدن این راهنما اجرا نمی‌شوند.

۱. چه چیزی تغییر کرده؟

اتصال قدیمی با کلید ثابت Pusher دیگر مبنای این پیاده‌سازی نیست. سایت Kick اکنون descriptor اتصال را ارائه می‌کند؛ در بررسی زنده، provider آن centrifugo بود. کلاینت باید توکن موقت بگیرد و با پروتکل Centrifugo به کانال چت Subscribe کند.

مرورگر برنامه←Worker: bootstrap و token←API عمومی سایت Kick
مرورگر↔Worker: WebSocket relay↔Centrifugo در Kick

در بررسی از دامنهٔ برنامه، درخواست مستقیم مرورگر برای توکن با CORS شکست خورد و WebSocket مستقیم نیز خطای شبکه داد. Worker هر دو مسیر را واسطه‌گری می‌کند. APIهای داخلی سایت Kick قرارداد رسمی پایدار ندارند؛ آدرس سرور از descriptor گرفته می‌شود و به یک region ثابت وابسته نیستیم.

این مسیر برای خواندن چت عمومی از توکن اتصال ناشناس استفاده می‌کند. Firebase، Client Secret و ورود OAuth برای این Worker مستقل لازم نیستند. این توکن اجازهٔ ارسال پیام به چت Kick را در این نمونه فراهم نمی‌کند.

برای پروژهٔ دیگر، SITE_ORIGIN باید origin واقعی همان برنامه باشد؛ مثلاً https://your-app.example. مسیر صفحه مانند /instaQ/ یا slash انتهایی به آن اضافه نکن. Worker این پروژه درخواست دامنه‌های دیگر را قبول نمی‌کند؛ برنامه‌نویس دیگر باید Worker خودش را بسازد.

۳. قرارداد HTTP بین مرورگر و Worker

مسیرورودیخروجی / کار
POST /chat/bootstrap{channel, clientId}{provider, url, token, channelId, roomId}
POST /chat/token{clientId}{token} برای تمدید
GET /chat/socket?host=...درخواست Upgrade: websocketrelay به host تأییدشدهٔ Kick
GET /healthنداردنسخهٔ کد Worker

clientId با crypto.randomUUID() ساخته می‌شود و در اتصال مجدد همان کلاینت ثابت می‌ماند؛ شناسهٔ کاربر Kick نیست.

Worker ابتدا از https://kick.com/api/v2/channels/{slug} دو شناسهٔ متفاوت می‌گیرد: channelId از فیلد id و roomId از chatroom.id. سپس descriptor از POST https://web.kick.com/api/v1/realtime/channels/{channelId}/chat/connection و توکن از POST https://web.kick.com/api/v1/realtime/auth/connection دریافت می‌شود.

نام کانال یا URL آن را وارد کن. در این نسخه ورودی عددی chatroom ID به‌تنهایی پشتیبانی نمی‌شود.

۴. پروتکل WebSocket

  1. مرورگر به مسیر WebSocket در Worker وصل می‌شود؛ Worker فقط hostهای realtime.*.platform.kick.com را می‌پذیرد و مقصد آن ثابتاً /connection/websocket است.
  2. فرمان اتصال: {id:1, connect:{token, name:"js"}}.
  3. بعد از پاسخ connect، فرمان عضویت: {id:2, subscribe:{channel:"chatrooms.ROOM_ID.v2"}}.
  4. فقط بعد از پاسخ subscribe وضعیت «متصل» نشان داده می‌شود. این وضعیت به‌تنهایی ثابت نمی‌کند پیام دریافت شده؛ یک پیام جدید باید به callback برسد.
  5. پیام‌ها از push.pub.data می‌آیند. event باید به ChatMessageEvent ختم شود. data داخلی ممکن است رشتهٔ JSON باشد و باید دوباره Parse شود.

یک فریم می‌تواند چند JSON مستقل داشته باشد که با newline جدا شده‌اند؛ کلاینت فریم را با split("\n") به بسته‌ها تقسیم می‌کند.

نگه‌داشتن اتصال

  • پاسخ connect، مقادیر ping و pong را اعلام می‌کند. پیام خالی {} heartbeat است؛ در صورت درخواست سرور با {} پاسخ داده می‌شود.
  • اگر تا interval به‌علاوهٔ مهلت اضافه هیچ فریمی نرسد، اتصال دوباره برقرار می‌شود.
  • اگر expires فعال باشد، با استفاده از ttl، توکن قبل از انقضا گرفته و فرمان refresh ارسال می‌شود.
  • Reconnect با backoff و jitter انجام می‌شود؛ هر بار bootstrap و Subscribe مجدد انجام می‌شود. تاریخچهٔ پیام‌های ازدست‌رفته در این نمونه بازیابی نمی‌شود.
  • هنگام stop، تایمرها، درخواست‌های fetch و سوکت پاک می‌شوند؛ شمارهٔ generation جلوی callbackهای اتصال قبلی را می‌گیرد.

در instaQ، تابع scan(content, username, time) بدون تغییر در parser اصلی، لینک را وارد صف می‌کند. شناسایی Instagram، YouTube و TikTok، از جمله vt و vm، به همان تنظیمات انتخاب منابع وابسته است؛ منبع غیرفعال عمداً وارد صف نمی‌شود.

محدودیت کل ورودی، سقف هر کاربر، Data Saver، سابقهٔ دیده‌شده‌ها و کنترل پخش در لایهٔ برنامه باقی مانده‌اند. برای جلوگیری از پردازش تکراری، instaQ حداکثر ۱۵۰۰ شناسهٔ پیام اخیر را نگه می‌دارد. پیام بدون ID همچنان از قواعد جلوگیری از لینک تکراری در scan عبور می‌کند.

برای یکتایی حساب از kickId استفاده کن؛ username برای نمایش مناسب است. متن چت را با textContent نمایش بده و توکن موقت را در لاگ یا localStorage ذخیره نکن. کلاینت پایین توکن را در حافظهٔ همان اتصال نگه می‌دارد.

۶. فایل کامل kick-realtime.js

بدون کتابخانهٔ خارجی اجرا می‌شود. آدرس ثابت Worker در ابتدای این کد را برای پروژهٔ خودت تغییر بده. این کد در راهنما اجرا نمی‌شود؛ آن را در فایل جداگانه ذخیره کن.

JavaScript / JSON
// Anonymous public chat. Native Centrifugo JSON protocol; no OAuth or Pusher key.
(()=>{
 const worker='https://instaq-chat.ahmadamj79.workers.dev';
 function connect({channel,onState=()=>{},onMessage=()=>{}}){
  const clientId=crypto.randomUUID();let stopped=false,socket=null,controller=null,attempt=0,generation=0,retryTimer,heartbeatTimer,refreshTimer,deadlineTimer;
  let commandId=0,pingMs=35000,needsPong=false,roomChannel='',commands=new Map();
  const emit=(state,message)=>{if(!stopped)onState(state,message);};
  const clearTimers=()=>{clearTimeout(heartbeatTimer);clearTimeout(refreshTimer);clearTimeout(deadlineTimer);};
  async function api(path,body,signal){
   let response;try{response=await fetch(worker+path,{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify(body),signal});}catch(error){throw Error('دسترسی به Worker ناموفق است؛ شبکه یا CORS: '+error.message);}
   let data;try{data=await response.json();}catch{throw Error('پاسخ سرویس چت معتبر نیست.');}
   if(!response.ok)throw Error(response.status===404?'Worker چت هنوز به نسخهٔ جدید ارتقا پیدا نکرده است.':data.error||'خطای سرویس چت '+response.status);
   return data;
  }
  function retry(token,message){
   if(stopped||token!==generation)return;generation++;clearTimers();controller?.abort();commands.clear();
   const old=socket;socket=null;if(old){old.onopen=old.onmessage=old.onclose=old.onerror=null;try{old.close();}catch{}}
   emit('disconnected',message||'اتصال قطع شد؛ تلاش دوباره…');
   clearTimeout(retryTimer);retryTimer=setTimeout(start,Math.min(15000,800*2**Math.min(attempt++,4))+Math.random()*400);
  }
  async function start(){
   if(stopped)return;const token=++generation;controller?.abort();controller=new AbortController();const signal=controller.signal;
   emit('connecting','در حال اتصال به چت Kick…');
   deadlineTimer=setTimeout(()=>retry(token,'دریافت اتصال چت بیش از حد طول کشید.'),40000);
   try{
    const config=await api('/chat/bootstrap',{channel,clientId},signal);if(stopped||token!==generation)return;
    if(config.provider!=='centrifugo'||!Number.isSafeInteger(config.roomId)||config.roomId<=0)throw Error('تنظیمات اتصال چت نامعتبر است.');
    const url=new URL(config.url);if(url.protocol!=='wss:'||!url.hostname.endsWith('.platform.kick.com'))throw Error('آدرس اتصال چت نامعتبر است.');
    roomChannel='chatrooms.'+config.roomId+'.v2';commands=new Map();commandId=0;
    const relay=new URL(worker+'/chat/socket');relay.protocol='wss:';relay.searchParams.set('host',url.hostname);
    const ws=new WebSocket(relay.href);socket=ws;
    const current=()=>!stopped&&token===generation&&socket===ws;
    const send=(type,data,callback)=>{if(!current()||ws.readyState!==WebSocket.OPEN)return;const id=++commandId;commands.set(id,callback);ws.send(JSON.stringify({id,[type]:data}));};
    const alive=()=>{clearTimeout(heartbeatTimer);heartbeatTimer=setTimeout(()=>retry(token,'چت پاسخ نمی‌دهد؛ اتصال دوباره…'),pingMs);};
    function renew(result){
     clearTimeout(refreshTimer);if(!result.expires||!Number.isFinite(result.ttl))return;
     refreshTimer=setTimeout(async()=>{try{const auth=await api('/chat/token',{clientId},signal);if(current())send('refresh',{token:auth.token},renew);}catch(error){if(current())retry(token,error.message);}},Math.max(1000,(result.ttl-20)*1000));
    }
    function publication(pub){
     let envelope=pub?.data;if(typeof envelope==='string')try{envelope=JSON.parse(envelope);}catch{return;}
     if(!envelope?.event?.endsWith('ChatMessageEvent'))return;
     let data=envelope.data;if(typeof data==='string')try{data=JSON.parse(data);}catch{return;}
     if(typeof data?.content!=='string')return;
     onMessage({content:data.content,username:String(data.sender?.username||data.sender?.slug||data.sender?.id||''),id:data.id??data.message_id,time:data.created_at,kickId:data.sender?.id});
    }
    ws.onopen=()=>{if(current())send('connect',{token:config.token,name:'js'},result=>{
     needsPong=!!result.pong;pingMs=result.ping>0?(result.ping+10)*1000:45000;alive();renew(result);
     send('subscribe',{channel:roomChannel},()=>{clearTimeout(deadlineTimer);attempt=0;emit('connected','Kick Live');});
    });};
    ws.onmessage=event=>{
     if(!current())return;alive();
     for(const line of String(event.data).trim().split('\n')){
      let reply;try{reply=JSON.parse(line);}catch{continue;}
      if(!Object.keys(reply).length){if(needsPong)ws.send('{}');continue;}
      if(reply.id){const callback=commands.get(reply.id);commands.delete(reply.id);if(reply.error){retry(token,'خطای چت '+reply.error.code+': '+reply.error.message);return;}const value=reply.connect||reply.subscribe||reply.refresh;if(callback&&value)callback(value);}
      else if(reply.push){const push=reply.push;if(push.disconnect||push.unsubscribe&&push.channel===roomChannel){retry(token,'اتصال چت نیاز به تمدید دارد.');return;}if(push.channel===roomChannel&&push.pub)publication(push.pub);}
     }
    };
    ws.onerror=()=>{if(current())retry(token,'اتصال WebSocket روی Worker برقرار نشد ('+url.hostname+'). شبکه یا محدودیت مرورگر را بررسی کن.');};
    ws.onclose=event=>{if(current())retry(token,'اتصال چت قطع شد ('+event.code+').');};
   }catch(error){if(!stopped&&token===generation)retry(token,error.message);}
  }
  start();
  return {close(){if(stopped)return;stopped=true;generation++;clearTimeout(retryTimer);clearTimers();controller?.abort();commands.clear();if(socket){socket.onopen=socket.onmessage=socket.onerror=socket.onclose=null;try{socket.close();}catch{}socket=null;}}};
 }
 window.KickRealtime={connect};
})();

۷. کد کامل Worker مستقل

این نسخه فقط دروازهٔ چت است و کد احراز هویت و Firebase در آن وجود ندارد. کد را تماماً جایگزین فایل Worker کن. محدودیت origin، اعتبارسنجی ورودی، timeout و محدودکردن مقصد relay در همین فایل هستند. بررسی origin جای احراز هویت برای اطلاعات خصوصی را نمی‌گیرد؛ این Worker برای چت عمومی طراحی شده است.

JavaScript / JSON
// instaQ public Kick chat gateway — Cloudflare Workers Free. No secrets or bindings.
async function readBody(request){
  if(!request.headers.get('content-type')?.startsWith('application/json'))throw Error('content type');
  const reader=request.body?.getReader();if(!reader)throw Error('body');
  let size=0;const chunks=[];
  try{while(true){const {value,done}=await reader.read();if(done)break;size+=value.byteLength;if(size>8192){await reader.cancel();throw Error('body too large')}chunks.push(value);}}
  finally{reader.releaseLock()}
  const bytes=new Uint8Array(size);let offset=0;for(const chunk of chunks){bytes.set(chunk,offset);offset+=chunk.length}
  return JSON.parse(new TextDecoder().decode(bytes));
}
const chatRooms=new Map();
async function chatUpstream(path,body){
 const response=await fetch('https://web.kick.com/api/v1/realtime/'+path,{method:'POST',headers:{'Content-Type':'application/json',Accept:'application/json',Origin:'https://kick.com',Referer:'https://kick.com/','User-Agent':'Mozilla/5.0'},body:JSON.stringify(body),signal:AbortSignal.timeout(10000)});
 if(!response.ok)throw Error('Kick realtime HTTP '+response.status);
 return (await response.json()).data;
}
async function publicChat(path,body){
 const clientId=body.clientId;
 if(typeof clientId!=='string'||!/^[a-f0-9]{8}-[a-f0-9]{4}-4[a-f0-9]{3}-[89ab][a-f0-9]{3}-[a-f0-9]{12}$/i.test(clientId))throw Error('Invalid clientId');
 if(path==='/chat/token'){
  const data=await chatUpstream('auth/connection',{client_id:clientId});if(typeof data?.token!=='string')throw Error('Missing connection token');return {token:data.token};
 }
 const channel=String(body.channel||'').toLowerCase();
 if(!/^[a-z0-9][a-z0-9_-]{0,63}$/.test(channel)||/^\d+$/.test(channel))throw Error('نام کانال Kick را وارد کن، نه شناسهٔ عددی چت.');
 let room=chatRooms.get(channel);
 if(!room||room.until<Date.now()){
  const response=await fetch('https://kick.com/api/v2/channels/'+encodeURIComponent(channel),{headers:{Accept:'application/json','User-Agent':'Mozilla/5.0',Referer:'https://kick.com/'},signal:AbortSignal.timeout(10000)});
  if(!response.ok)throw Error('Kick channel HTTP '+response.status);
  const data=await response.json(),channelId=Number(data?.id),roomId=Number(data?.chatroom?.id);
  if(!Number.isSafeInteger(channelId)||channelId<=0||!Number.isSafeInteger(roomId)||roomId<=0)throw Error('Channel or chatroom ID missing');
  room={channelId,roomId,until:Date.now()+300000};chatRooms.set(channel,room);if(chatRooms.size>100)chatRooms.delete(chatRooms.keys().next().value);
 }

export default {
 async fetch(request,env){
  const headers={'Cache-Control':'no-store','Vary':'Origin','Content-Type':'application/json; charset=utf-8'};
  const reply=(status,data)=>new Response(JSON.stringify(data),{status,headers});
  if(request.method==='GET'&&new URL(request.url).pathname==='/health')return reply(200,{ok:true,version:'centrifugo-1'});
  if(!env.SITE_ORIGIN||request.headers.get('Origin')!==env.SITE_ORIGIN)return reply(403,{error:'Origin not allowed'});
  headers['Access-Control-Allow-Origin']=env.SITE_ORIGIN;
  headers['Access-Control-Allow-Methods']='POST, OPTIONS';headers['Access-Control-Allow-Headers']='Content-Type';
  if(request.method==='OPTIONS')return new Response(null,{status:204,headers});
  if(new URL(request.url).pathname==='/chat/socket'){
   if(request.method!=='GET'||request.headers.get('Upgrade')?.toLowerCase()!=='websocket')return reply(426,{error:'WebSocket upgrade required'});
   const host=new URL(request.url).searchParams.get('host');
   if(!/^realtime\.[a-z0-9-]+\.platform\.kick\.com$/.test(host||''))return reply(400,{error:'Invalid Kick realtime host'});
   try{
    const upstream=await fetch('https://'+host+'/connection/websocket',{headers:{Upgrade:'websocket',Origin:'https://kick.com','User-Agent':'Mozilla/5.0'}});
    if(!upstream.webSocket)return reply(502,{error:'Kick WebSocket upgrade failed'});
    // Return the upgrade directly: Cloudflare relays frames without per-message JS execution.
    return upstream;
   }catch{return reply(502,{error:'Kick WebSocket unavailable'});}
  }
  if(request.method!=='POST')return reply(405,{error:'Method not allowed'});
  const chatPath=new URL(request.url).pathname;
  if(['/chat/bootstrap','/chat/token'].includes(chatPath)){
   try{return reply(200,await publicChat(chatPath,await readBody(request)));}
   catch(error){return reply(502,{error:'اتصال چت Kick ناموفق بود: '+String(error.message||'upstream error').slice(0,150)});}
  }
  return reply(404,{error:'Not found'});

۸. عیب‌یابی

علامتبررسی
403 از WorkerSITE_ORIGIN باید دقیقاً با Origin مرورگر برابر باشد. فایل محلی با Origin: null پذیرفته نمی‌شود.
Worker پیدا نمی‌شود / Failed to fetchنام و آدرس Worker، Deploy، DNS و دسترسی شبکه به workers.dev را بررسی کن.
502 با Kick channel HTTP 404slug کانال اشتباه است؛ نام نمایشی و شناسهٔ کانال یکسان فرض نشوند. URL واقعی کانال را وارد کن.
502 با HTTP 403 از Kickدرخواست خروجی Worker توسط سرویس بالادستی رد شده است؛ این خطا با خطای origin مرورگر متفاوت است.
bootstrap موفق، WebSocket ناموفقدر Network → WS مسیر /chat/socket را بررسی کن؛ فیلتر شبکه، handshake و خطای gateway مهم‌اند.
متصل، ولی لینک وارد صف نمی‌شودشمارندهٔ پیام دریافتی، نام کانال، انتخاب منبع، لینک تکراری، قفل ورودی و سقف لینک‌ها را بررسی کن.
بعد از مدتی قطع می‌شودHeartbeat، تمدید توکن، sleep شدن دستگاه و reconnect را بررسی کن.
چند بار دریافت می‌شودفقط یک کلاینت فعال بساز، قبل از تعویض کانال close کن و dedup بر اساس message.id داشته باش.
اتصال، دریافت پیام و پذیرفته‌شدن آن توسط منطق برنامه سه مرحلهٔ جدا هستند. در ChatBattle متن دقیق 1 یا 2 فقط هنگام رأی‌گیری فعال شمرده می‌شود؛ در instaQ متن باید لینک معتبر از منبع فعال داشته باشد. فیلتر رأی ChatBattle را به برنامهٔ دریافت لینک منتقل نکن.

۹. منابع و کد پروژه

  • سورس instaQ — فایل‌های instaQ.html، kick-realtime.js و worker/worker.mjs.
  • پروتکل رسمی Centrifugo — connect، subscribe، framing، heartbeat و refresh.
  • WebSocket در Cloudflare Workers و پاسخ Upgrade و relay.
  • مسیر رسمی جایگزین Kick: Events/Webhooks — برای معماری مبتنی بر chat.message.sent، مستقل از مسیر داخلی وب‌سایت.
