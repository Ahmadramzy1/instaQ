# instaQ

**صف پخش لینک‌های اینستاگرام برای چت کیک** — ریل‌ها و پست‌ها را به همان ترتیبی که بینندگان می‌فرستند پخش می‌کند.

«instaQ» یک برنامه‌ی وب تک‌فایلی است که به چت [کیک](https://kick.com) وصل می‌شود، لینک‌های اینستاگرامی که بینندگان می‌فرستند را پیدا می‌کند و ویدیوها را به‌ترتیب، یکی‌یکی، در یک پلیر تمام‌قد پخش می‌کند. نیازی به نصب، سرور یا وابستگی نیست؛ فقط یک فایل HTML.

## امکانات

- **صفحه‌ی ورود** — نام چنل یا چت‌روم آیدی را وارد می‌کنید و بعد از اتصال وارد صفحه‌ی اصلی می‌شوید (نام چنل و چت‌روم آیدی در صفحه‌ی اصلی نمایش داده نمی‌شود).
- **تشخیص خودکار لینک** — ریل، پست، IGTV و لینک‌های `/share/`، با `https://` یا بدون آن. لینک‌های تکراری نادیده گرفته می‌شوند. استوری داخل صفحه پخش نمی‌شود و دکمه‌ی «باز کردن در اینستاگرام» دارد.
- **صف مرتب** — لینک‌ها به ترتیب ارسال پخش می‌شوند؛ صف تا ۱۵۰ مورد را نگه می‌دارد و در مرورگر ذخیره می‌شود، پس با رفرش پاک نمی‌شود.
- **پخش مستقیم ویدیو** — چند آینه و صفحه‌ی embed اینستاگرام هم‌زمان امتحان می‌شوند، اولین منبع سالم برنده است و موارد ناموفق یک‌بار خودکار دوباره تلاش می‌شوند. اگر هیچ‌کدام کار نکرد، پلیر خود اینستاگرام نمایش داده می‌شود.
- **پلیر تمام‌قد** — نوار اطلاعات و کنترل‌ها روی ویدیو قرار دارند و وقتی ماوس از روی پلیر برداشته شود (بعد از ۱ ثانیه) یا بی‌حرکت بماند (۳ ثانیه) محو می‌شوند.
- **کنترل‌های پلیر** — تایم‌لاین قابل جابه‌جایی با نمایش زمان هنگام هاور، قبلی / بعدی، ۵ ثانیه جلو و عقب، پخش / مکث، سرعت (۱× / ۱.۲۵× / ۱.۵× / ۲×)، تکرار، پخش خودکار، بی‌صدا و تمام‌صفحه.
- **ابزارهای صف** — فیلتر «فقط ندیده‌ها»، «توقف افزودن»، حذف تک‌تک موارد، پاک کردن دیده‌شده‌ها و پاک کردن کل لیست.
- **محدودیت‌ها (نوار پایین صفحه)** — **محدودیت تعداد ورودی** (حداکثر تعداد کل لینک‌هایی که وارد صف می‌شود) و **سقف لینک هر کاربر** (حداکثر لینکی که هم‌زمان از یک کاربر در صف می‌ماند). مقدار فعلی روی دکمه‌ها نشان داده می‌شود.
- **تم و زبان** — تم تیره / روشن و رابط فارسی (راست‌به‌چپ) / انگلیسی.

## نحوه‌ی استفاده

۱. فایل `instaQ.html` را دانلود کنید و در یک مرورگر مدرن باز کنید، یا آن را روی GitHub Pages بگذارید.
۲. نام چنل کیک (یا چت‌روم آیدی) را بنویسید و **اتصال** را بزنید.
۳. لینک‌هایی که در چت ظاهر شوند خودکار پخش می‌شوند.
## میانبرهای صفحه‌کلید

| کلید | عملکرد |
|---|---|
| `Space` | پخش / مکث |
| `←` / `→` | ۵ ثانیه عقب / جلو |
| `N` / `P` | بعدی / قبلی |
| `M` | بی‌صدا |
| `F` | تمام‌صفحه |
| `Del` | حذف مورد فعلی |

## تنظیمات

منوی ⚙ شامل **تغییر چنل**، **پاک کردن دیده‌شده‌ها** و **پاک کردن کل لیست** است. مبدل دلخواه ویدیو (با `{t}` برای نوع و `{c}` برای کد پست) و کلید دلخواه Pusher هنوز در کد پشتیبانی می‌شوند ولی دکمه‌شان مخفی است؛ لینک «کلید Pusher» در صفحه‌ی ورود در دسترس می‌ماند.

## نحوه‌ی کار

- نام چنل از طریق API عمومی کیک (با پروکسی‌های CORS) به چت‌روم آیدی تبدیل و در مرورگر ذخیره می‌شود.
- پیام‌های چت از طریق WebSocket سرویس Pusher روی کانال `chatrooms.<id>.v2` دریافت می‌شوند و در صورت قطع شدن، اتصال خودکار دوباره برقرار می‌شود.
- لینک‌های اینستاگرام با عبارت منظم پیدا می‌شوند و بعد از طریق آینه‌های عمومی و صفحه‌ی embed اینستاگرام به آدرس مستقیم ویدیو تبدیل می‌شوند.
- همه‌چیز سمت کاربر اجرا می‌شود؛ تنظیمات و صف در `localStorage` ذخیره می‌شوند.

## محدودیت‌های شناخته‌شده

- برنامه به سرویس‌های بیرونی (API کیک، پروکسی‌های CORS، آینه‌های اینستاگرام) وابسته است. اگر یکی از آن‌ها تغییر کند یا از کار بیفتد، پیدا کردن ویدیو ممکن است شکست بخورد؛ دکمه‌ی تلاش مجدد یا پلیر اینستاگرام را امتحان کنید.
- اگر کیک دروازه‌ی چت را ببندد (خطای `4001`)، احتمالاً کلید Pusher عوض شده است؛ از صفحه‌ی ورود کلید جدید را وارد کنید.
- بسته به شبکه، برای بعضی منابع ممکن است به VPN نیاز باشد.
- استوری داخل صفحه پخش نمی‌شود.
